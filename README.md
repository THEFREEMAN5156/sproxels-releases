# Sproxels

Downloads for Sproxels, a path-traced cube sandbox. It's in early testing, so expect rough edges.

## Windows

1. Open the [latest release](https://github.com/THEFREEMAN5156/sproxels-releases/releases/latest).
2. Download the file ending in `Setup.exe`.
3. Run it. Windows will probably say "Windows protected your PC". That happens because the game isn't signed with a paid certificate. Click **More info**, then **Run anyway**.
4. Sproxels installs itself, adds a shortcut and opens.

## Linux

1. Open the [latest release](https://github.com/THEFREEMAN5156/sproxels-releases/releases/latest).
2. Download the file ending in `.AppImage`.
3. Double-click it. If your system asks, allow it to run as a program.

## Updating

When a new version is out, the menu shows an **Update now** button. You won't need to download anything by hand.

## If it crashes

Next time you open the game, click **Open crash folder** in the menu and send the newest files to the creator.
